# Practicar Taula Periòdica

Una aplicació web interactiva i moderna dissenyada per ajudar estudiants i entusiastes a aprendre i practicar els elements de la taula periòdica i els seus estats d'oxidació de forma visual i intuïtiva.

## ✨ Característiques

- **Taula Interactiva:** Explora tots els elements químics de forma visual.
- **Detalls dels Elements:** Consulta informació rellevant de cada element: nom, número atòmic, símbol i estats d'oxidació.
- **Categorització per Colors:** Elements agrupats visualment per les seves propietats químiques.
- **Pràctica de Símbols i Valències:** Moda d'examen configurable per practicar escrivint els símbols o bé els estats d'oxidació (valències).
- **Avaluació Flexible d'Estats d'Oxidació:** La correcció té en compte les valències independentment de l'ordre introduït i accepta separadors per comes o espais.
- **Filtre d'Elements d'Examen:** Opció per seleccionar ràpidament els elements més importants/d'examen en un sol clic.
- **Correcció i Puntuació:** Avalua els teus coneixements amb resultats en temps real, comptador d'encerts i retroalimentació visual d'errors.

## 🛠️ Tecnologies Utilitzades

- **React:** Biblioteca per a la creació de la interfície d'usuari.
- **Vite:** Eina de generació de projectes ràpida per a frontend.
- **Tailwind CSS:** Framework de CSS per a un disseny ràpid i personalitzat.
- **Lucide React:** Icones modernes i netes per a la interfície.
- **JavaScript (ES6+):** Lògica de l'aplicació, filtratge flexible i gestió de dades JSON.

## 🚀 Començar

### Prerequisits

Assegura't de tenir instal·lat:
- [Node.js](https://nodejs.org/) (versió recomanada LTS)
- npm (ve inclòs amb Node.js)

### Instal·lació i Configuració

1. **Clona el repositori:**
```bash
git clone https://github.com/MilimNava-dev/taula-periodica.git
```

2. **Navega al directori del projecte:**
```bash
cd taula-periodica
```

3. **Instal·la les dependències:**
```bash
npm install
```

### Executar l'Aplicació

Per iniciar el servidor de desenvolupament, executa:

```bash
npm run dev
```

L'aplicació estarà disponible a `http://localhost:5173`.

## 📜 Scripts Disponibles

Dins del directori del projecte, pots executar:

* `npm run dev`: Inicia el servidor de desenvolupament amb recàrrega en calent.
* `npm run build`: Compila l'aplicació per a producció a la carpeta `dist`.
* `npm run lint`: Analitza el codi amb ESLint per mantenir la qualitat i l'estil.
* `npm run preview`: Previsualitza la versió de producció localment.
